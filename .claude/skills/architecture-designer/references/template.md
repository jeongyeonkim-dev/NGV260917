# 아키텍처 설계서 양식 — ⚠ 임시(INTERIM) 상태

**이 파일은 사용자가 지정할 실제 아키텍처 설계서 양식을 아직 받지 못해 임시로 채워둔 것이다.** 사용자가 양식을 제공하면 이 파일 전체를 그 내용으로 교체하고 이 경고 문구를 제거한다. 그 전까지 이 스킬로 작성하는 모든 아키텍처 산출물에는 "임시 양식 기준" 경고를 표시한다.

## 임시 목차 구성 (사용자 양식 수령 전까지 사용)

1. 아키텍처 개요 — 선정된 스타일, 선정 사유, 적용 범위, 관련 요구사항 ID
2. 정적 구조 — 컴포넌트 목록·책임, 계층 다이어그램
3. 인터페이스 명세 — 컴포넌트 쌍별 인터페이스 표(방향/데이터/타이밍/오류처리)
4. 동적 측면 — 시나리오별 시퀀스/상태 다이어그램
5. SOLID/설계원칙 점검 결과
6. 컴포넌트 통합 순서 — 단계/사전조건/스텁·드라이버/검증항목
7. 추적성 — 요구사항 ↔ 아키텍처 요소 매핑
8. 특수특성 및 분석 결과(SYS.3.BP3 대응)
9. 변경이력

## 사용 지침
- 이 임시 양식은 A-SPICE 4.1 SYS.3/SWE.2 산출물(04-06 System Architecture / 04-04 Software Architecture, 17-57 Special Characteristics, 13-51 Consistency Evidence)과 ISO 26262-6 Clause 7이 요구하는 최소 정보만 담고 있다. 실제 조직 양식은 이보다 항목이 많거나 순서·명칭이 다를 수 있다.
- 실제 양식을 받으면, 위 항목들이 실제 양식의 어떤 절에 대응하는지 매핑표를 이 파일 하단에 남겨 마이그레이션 누락을 방지한다.
