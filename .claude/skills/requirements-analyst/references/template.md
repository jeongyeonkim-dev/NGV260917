# 요구사항 템플릿 — ⚠ 임시(INTERIM) 상태

**이 파일은 사용자가 지정할 실제 템플릿을 아직 받지 못해 임시로 채워둔 것이다.** 사용자가 템플릿(항목, 필드, 양식)을 제공하면 이 파일 전체를 그 내용으로 교체하고 이 경고 문구를 제거한다. 그 전까지 이 스킬로 작성하는 모든 요구사항 산출물에는 "임시 템플릿 기준" 경고를 표시한다.

## 임시 필드 구성 (사용자 템플릿 수령 전까지 사용)

| 필드 | 설명 | 필수 |
|------|------|------|
| ID | 고유 식별자 (`references/traceability-scheme.md`의 채번 규칙 사용) | 필수 |
| 제목 | 한 줄 요약 | 필수 |
| 유형 | 기능(FR) / 비기능(NFR — ISO25010 특성 태깅) | 필수 |
| 레벨 | 이해관계자(STK) / 시스템(SYS) / 소프트웨어(SW) | 필수 |
| 출처(근거) | 이 요구사항이 파생된 상위 요구/니즈/규정 | 필수 |
| 설명 | 모호하지 않고 원자적인 서술문 | 필수 |
| 수용기준(FR) 또는 정량기준(NFR) | 측정 가능한 통과/실패 판정 기준 | 필수 |
| 검증방안 | 실행 가능한 검증 방법(테스트/분석/리뷰/시뮬레이션 등) | 필수 |
| 다이어그램 참조(FR) | UML/SysML 다이어그램 유형과 파일 경로 | FR은 필수 |
| 상위 추적 | 부모 요구사항 ID 목록 (없으면 "미배정") | 필수 |
| 하위 추적 | 자식(설계/테스트 등) ID 목록 (없으면 "미배정") | 필수 |
| 우선순위 | 예: 필수/권고/선택 | 권장 |
| 상태 | 초안 / 합의됨 / 변경중 / 폐기 | 필수 |
| 버전/변경이력 | 변경일, 변경사유, 변경자 | 권장 |

## 사용 지침
- 이 임시 템플릿은 ISO 26262-8 Clause 6과 A-SPICE 4.1 SYS.1/SYS.2/SWE.1 산출물(17-00 Requirement, 17-54 Requirement Attribute)이 요구하는 최소 정보만 담고 있다. 실제 조직 템플릿은 이보다 필드가 많거나 명칭이 다를 수 있다.
- 실제 템플릿을 받으면, 위 필드들이 실제 템플릿의 어떤 컬럼에 대응하는지 매핑표를 만들어 이 파일 하단에 남겨둔다(마이그레이션 시 누락 방지).
