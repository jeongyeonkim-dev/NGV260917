# 상세설계서 양식 — ⚠ 임시(INTERIM) 상태

**이 파일은 사용자가 지정할 실제 상세설계서 양식을 아직 받지 못해 임시로 채워둔 것이다.** 사용자가 양식을 제공하면 이 파일 전체를 그 내용으로 교체하고 이 경고 문구를 제거한다. 그 전까지 이 스킬로 작성하는 모든 상세설계 산출물에는 "임시 양식 기준" 경고를 표시한다.

## 임시 목차 구성 (사용자 양식 수령 전까지 사용)

1. 상세설계 개요 — 대상 컴포넌트, 관련 아키텍처 요소 ID, 관련 요구사항 ID
2. 단위 목록 및 정적 구조 — 단위 ID, 소속 컴포넌트, 책임
3. 단위 인터페이스 명세 — 파라미터별 방향/타입/유효범위/단위(unit)/오류처리
4. 동적 측면 — 단위 간 호출순서, 상태전이
5. 안전 코딩 원칙 반영 현황
6. 테스트 용이성 점검 결과
7. 추적성 — 요구사항 ↔ 아키텍처 ↔ 상세설계 ↔ 코드
8. 변경이력

## 사용 지침
- 이 임시 양식은 A-SPICE 4.1 SWE.3 산출물(04-05 Software Detailed Design, 11-05 Software Unit, 13-51 Consistency Evidence)과 ISO 26262-6 Clause 8이 요구하는 최소 정보만 담는다.
- 실제 양식을 받으면, 위 항목들이 실제 양식의 어떤 절에 대응하는지 매핑표를 이 파일 하단에 남긴다.
