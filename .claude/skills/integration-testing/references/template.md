# 통합시험 산출물 양식 — ⚠ 임시(INTERIM) 상태

**이 파일은 사용자가 지정할 실제 통합시험 산출물 양식을 아직 받지 못해 임시로 채워둔 것이다.** 사용자가 양식을 제공하면 이 파일 전체를 그 내용으로 교체하고 이 경고 문구를 제거한다. 그 전까지 이 스킬로 작성하는 모든 통합시험 산출물에는 "임시 양식 기준" 경고를 표시한다.

## 임시 목차 구성 (사용자 양식 수령 전까지 사용)

1. 통합시험 개요 — 대상 범위, 참조 아키텍처/통합순서 문서 ID
2. 통합 단계별 시험 계획 및 결과
3. 시험 케이스 목록 (기법/긍정·부정/결과 포함)
4. 구조적 커버리지 결과 (함수 커버리지, Call 커버리지, 미달 항목 조치)
5. 추적성 (시험측정 ↔ 아키텍처/상세설계, 시험결과 ↔ 시험측정)
6. 종합 및 전달
7. 변경이력

## 사용 지침
- 이 임시 양식은 A-SPICE 4.1 SWE.5 산출물(08-60 Verification Measure, 08-58 Verification Measure Selection Set, 15-52 Verification Results, 13-51 Consistency Evidence, 01-50 Integrated Software)과 ISO 26262-6의 통합시험 요구사항이 필요로 하는 최소 정보만 담는다.
- 실제 양식을 받으면, 위 항목들이 실제 양식의 어떤 절에 대응하는지 매핑표를 이 파일 하단에 남긴다.
